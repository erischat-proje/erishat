# Bastet’in Hazinesi and Firavun book repair

Original 5×4, 40-line Egyptian cat game. Same fixed line set as the established Kovboy interface; dedicated engine, routes, RNG configuration and PNG assets. No other game math or open bonuses changed.

First-reel four-cell identical white/black cat stack locks matching cats and Wilds when no line win exists. Each later respin is a separate free server transaction. Locks persist until a line win, without forced wins, a hidden trial limit or a blocking loop. Sticky bonus Wilds retain position and 2×/3× value on reels 2–5. Matching Wild multipliers multiply (2××3×=6×). Initial bonus stack grants +2 spins once, not on subsequent respin transactions. Three/four/five Scatter award 8/12/16 spins. Buy: 100× stake, eight spins; maximum complete-round payout 5000×.

Existing User.lidya and dede_wallet fractional ledger, user-row locking, archived UUID receipts, ownership/sequence/stake checks and active-round resume are reused. Purchase cancellation is client-side; only confirmation sends the paid request. Base respins do not consume pending bonus spins. A final bonus spin with a pending respin remains resumable.

Firavun repair removes the three white CSS page planes and reveals a new textured book-open-v2 PNG. Its rules, selected symbol, RNG and bonus states are unchanged. HTML cache versions are refreshed.

Artwork: generated premium PNG atlas, 12 exported symbol sprites, 2:1 cover and separate textured opened book. Prompts: Egyptian gold/turquoise/lapis 4×3 symbol atlas; Bastet’in Hazinesi two-cat temple cover; open ochre papyrus spell book, no white pages. Built-in image generation used. Game sound is bounded synthesized feline contour/purr and Egyptian scale music, not recordings of real cats. Mute, close/background cleanup, reduced motion and shared bet controls are inherited.

Validation: 27 isolated engine/API tests (11 Bastet, 16 Firavun), JS syntax, diff whitespace, independent 100000 normal rounds and 30000 buys, including full respin chains/sticky wilds/retriggers/cap. Seed, sample and confidence intervals are in bastet-statistics.json. Target 96.20% is not certified; observed normal RTP 88.11162% (CI 71.26401–104.95923%), buy 100.25794% (CI 95.97284–104.54304%). Calibration remains pending. This PR is draft and is not deployed. Live database concurrency/production load was not tested. Chromium browser QA passed at 320/390/1024px in both themes: PNG decode, dedicated routing, shared bet increments, modal cleanup, buy cancellation/confirmation and one purchase request. Actual Android device QA remains pending.
