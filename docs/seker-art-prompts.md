# Şeker Sarayı: görsel üretim

İki asset built-in image generation ile yeni raster PNG olarak üretildi. Semboller Canvas native çizim veya emoji ile üretilmedi. Atlasın 12 ana alpha bileşeni ayrılarak aynı sanat eseri, ölçek korunarak 4×3 kare hücreye paketlendi. PNG alpha korundu. Scene 1024×1536, final atlas 1024×768.

## Sembol atlası prompt'u

Use case: stylized-concept. Asset: production transparent PNG sprite atlas for an original premium mobile game LIDYA ŞEKER SARAYI. Create exactly twelve isolated glossy 3D icons in a precisely regular 4 column x 3 row square atlas. Each icon fully within its equal square cell, abundant transparent margins, no shadows outside cell, no labels/text, no UI. Row 1: golden-yellow banana bunch, shiny red apple, purple grapes bunch, blue-purple plum. Row 2: sliced red watermelon, faceted blue candy, faceted emerald-green candy, wrapped violet candy. Row 3: ruby heart candy, pink-and-gold spiral lollipop on stick (scatter), luxurious golden spherical sugar bomb with short glowing fuse (blank face), ancient Lydian gold coin with lion engraving. Premium jewel-like sugar glass and polished surfaces, fine golden accents, consistent soft studio lighting, beautifully sculpted forms, very readable silhouettes at 64 pixels. Original design, true transparent background. Output one square 1536x1536 or higher resolution atlas, exactly 4x3 cells evenly spaced.

## Saray sahnesi prompt'u

Use case: stylized-concept. Production background for original premium mobile game LIDYA ŞEKER SARAYI, portrait 1024x1536. Lavish ancient Lydian palace reimagined as a jewel candy garden, rose quartz arches, polished ivory marble, embossed antique gold frames, pastel pink and purple sky, glossy sugar crystals, elegant small gold lion sculptures at lower corners. Dramatic cinematic high quality 3D illustration. Composition: outer architectural frame, spacious dark plum unobstructed rectangular central area (middle 60 percent width and 50 percent height) reserved for a 6x5 game board, subtle candy blossoms on edges. No symbols or grid or text or buttons drawn in the central reserved area. Top sunlit palace pediment, bottom marble balcony. Beautiful high end art direction, original design, no existing casino branding, no words or watermark.

Dosyalar: `frontend/assets/lidya-seker/symbols.png`, `frontend/assets/lidya-seker/scene.png`. Gösterim native Canvas drawImage; grafikler gerçek üretilmiş PNG dosyalarıdır. Atlasın son altın para hücresi dekoratif rezervdir, ödeme tablosuna dahil değildir.
