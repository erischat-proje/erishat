UNO açıldığında lobi odadaki herkese ve sonradan katılanlara gösterilir. Ana oyun paneli kaydırılmadan ekrana sığar; fazla kartlara ok düğmeleriyle geçilir. UNO sırasında sohbet başlangıcı aşağı taşınır.

50–300 Lidya ortak bahis seçimi, Hazırım ile tahsilat, hazırdan çıkış/iptal/süre dolumunda iade, tekli tam havuz ve eşli eşit paylaşım eklendi. Puanlı maç yalnızca maç sonunda ödenir. Bakiyeler ve oyun kaydı aynı işlemde, kullanıcı→oda kilit sırasıyla güncellenir; istek tekrarları ikinci tahsilat/ödeme yapmaz.

Doğrulama: 47 Python testi, 120 otomatik oyun, Node ön yüz durum testleri ve sözdizimi/diff kontrolleri. Gerçek cihaz yerleşimi ve canlı PostgreSQL eşzamanlılık kontrolü tamamlanmadı. API ve web birlikte dağıtılmalı.
