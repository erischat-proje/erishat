# Lidya Altın Şöleni

Original Irish-themed 5×3/25-line Copy Reels and four-grid Hold & Win game. This implements the user's specification under an original ErisChat name; it does not reproduce or certify a provider's proprietary RNG/reel strips.

## Rules

- 25 fixed, distinct left-to-right lines; normal 3/4/5 matches. Tree Wild substitutes for normal symbols on reels 2/3/4 only, never Money. Highest normal 5-match payout: 4× stake on a line.
- Three identical high symbols on reel 1 copy that reel to one or more other reels. Evaluate lines and count Money AFTER copying; copied reels can remove a previously present Money symbol.
- Six or more Money pots seed four separate 15-cell boards. Initial pots are distributed once without duplication, one per board first, then random empty cells. Buy costs 100× stake and seeds six pots/eight respins.
- Each respin decrements the remaining counter once. Landings: money pot, multiplier (2/3/5/10/25×), +1 respin or empty. Every landing locks in its cell. New pots do not reset the counter to eight. Each +1 landing adds one respin, once.
- A multiplier changes one uniformly selected existing pot on its OWN board. The multiplier remains locked; its effect occurs once. Seed distribution ensures at least one pot exists on every board. Values shown on cells are stake multiples.
- All 15 occupied cells, including multiplier/+1 cells, fill a board. Mini/Minor/Major/Grand awards: 20/50/200/5000×, once per board. Completed boards stop receiving landings. Bonus ends when all boards complete, no respins remain or the round cap is reached.
- Pots/jackpots are credited once when bonus ends. Paid-spin line wins are credited immediately and count against the same complete-round 5163× cap. Cap is checked during event application; remaining events are not applied after cap. Any residual respins then end.

The user's prompt does not define multiplier targeting scope or whether +1 cells count toward full-board jackpots. The choices above are explicitly shown in the UI.

## Integration

`altin_routes.py` uses existing User.lidya, dede_wallet fractional ledger, GameRound/GameBet/GamePlay, user row locks and archived UUID receipts. A late replay returns current balance without a second debit or credit. Round ownership, sequence and locked stake are checked; active bonus resumes across reloads. Client only displays server receipts. No production client RNG is loaded.

Router registrations for Altın Şöleni and existing Bastet are before the catch-all StaticFiles mount. No Bastet maths or open bonus rules change. Shared SlotStakes +/- bands and SlotBonusBuy price/balance confirmation are used. Register once in custom-game-routing.js; PNG cover is registered in the common premium cover mapper so it cannot be overwritten with a missing fallback.

## One-file demo

Package-root index.html embeds CSS, JavaScript, maths/config, all PNGs and generated synth audio. It makes no network requests and uses virtual balance only. Game state and receipts are kept in browser localStorage. Python/JS engine equality is tested with the same RNG streams for paid game, natural and purchased bonus steps. Production server controls actual Lidya.

## Artwork and audio

15 genuine generated PNG symbols and original 2:1 cover: 9/10/J/Q/K/A; harp; mushroom cottage; horseshoe; unicorn; friendly gold companion; Tree of Life; pot; multiplier gem; +1 clover. Built-in image generation prompts requested premium gold/emerald Irish raster artwork, transparent 4×4 atlas with clear gutters and an original Lidya Altın Şöleni cover. Extraction and sizing prepare these images for Canvas.

Canvas includes staggered reel animation, Copy Reels golden wave, split into four boards, sticky landings, multiplier beam, companion dance and coin/jackpot effect. RAF runs only while effects exist; idle uses a single draw. Background closes autoplay and stops sound; close cancels timers/observers/waiters and releases audio. Reduced motion supported. Irish-scale jig and stone/coin/magic cues are generated by bounded Web Audio synthesis: master gain .16, up to six voices, cooldown and cleanup. No MP3 or external sound dependency.

## Validation and maths

- 19 isolated engine/API tests plus 4 Python/JS parity tests; 27 regression tests for Bastet/Firavun. 50 total.
- Chromium 320/390/1024px, both themes; PNG decode, shared stake steps, four boards, confirm/cancel/one buy charge, persistent bonus resume/final payout and close. Standalone requested zero network resources.
- Actual-motion Copy Reels, multiplier, companion dance, jackpot and close-mid-animation; bounded audio/cleanup.
- Whitespace, Python compile, JS syntax. Installer sparse/three-way patch tree and SHA/ZIP CRC verified.
- Independent 500000 normal and 100000 purchased complete rounds, fixed seeds. Normal RTP estimate 95.122408% (95% CI 91.4285376–98.8162784%). Buy estimate 96.4185605% (95% CI 95.6408499–97.1962711%). Target 96.50% lies within both intervals; this is not a certified exact RTP. Full reports in altin-statistics.json; reproducible generator in tests/altin_simulate.py. Buy and natural bonus distributions are explicitly separate: landing rate and initial/new pot-value tables. Purchase confirmation mentions a separate buy distribution.

A draft PR is created by the installer; no automatic merge or deployment. Live PostgreSQL concurrent load and physical Android device QA were not run.
