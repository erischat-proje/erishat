# ErisChat

Android + iOS odaklı anonim sosyal sohbet platformu prototipi.

## v0.1
- Tıklanabilir keşfet ekranı
- Anonim avatar/profil mantığı
- Aktif kullanıcılar
- Sesli sohbet odası prototipi
- Mesajlar prototipi
- Profil ekranı
- Coin/cüzdan ve gizlilik menüsü için temel arayüz

## Yol haritası
1. HTML/UX prototipini genişlet
2. Flutter Android+iOS uygulamasına taşı
3. FastAPI backend
4. PostgreSQL + Redis
5. Gerçek zamanlı mesajlaşma
6. Sesli odalar/WebRTC
7. Moderasyon ve güvenlik
8. Coin/hediye/VIP sistemi
9. Admin paneli
