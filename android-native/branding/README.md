# ErisChat Lidya APK simgesi

Asıl görsel `lidya-launcher-master.png`: yerleşik ImageGen ile üretilen 1254×1254 gerçek PNG. Kodla çizilmiş logo değildir. Kaynak görselin mekanik boyutlandırılmasıyla beş Android yoğunluğunda normal ve adaptive foreground PNG dosyaları oluşturuldu. Altın amblem adaptive ikonun merkezdeki güvenli dairesinde kalır; arka plan zümrüt. Manifest mevcut adaptive ikon tanımını kullanır. Sürüm 8 / 1.7.

Üretim promptu: “Create a final production Android app launcher icon for ErisChat, a premium Turkish social chat app with the established Lidya (ancient Lydia) visual identity. Square 1024x1024 opaque full bleed deep emerald green background, subtly luminous polished dark emerald enamel, extremely subtle texture. A single bold sculpted warm gold emblem combining a dignified stylized Lydian lion head profile with a clearly recognizable speech bubble silhouette. Clean iconic silhouette, thick elegant gold forms, restrained premium embossed metal highlights, professionally art directed, simple enough to read at 48 pixels. The entire meaningful emblem must stay inside the central 60% of the square, plenty of plain emerald around all four sides for Android adaptive circle/squircle masks. Centered, balanced. No words, no letters, no initials, no crown, no coins, no casino elements, no phone mockup, no border frame, no rounded square outline, no external shadow, no white margin. Background must fill every pixel, not transparent. Deliver the standalone app icon artwork only.”

Doğrulama: 10 PNG boyutu ve adaptive altın amblemin merkez güvenli dairesi kontrol edildi. Bash sözdizimi ve APK indirme akışı taklit GitHub yanıtlarıyla sınandı. APK bu ortamda derlenmedi. PR birleştikten sonra GitHub Actions mevcut imza anahtarıyla APK üretir. `scripts/termux-lidya-apk-kur.sh` ana dalın aynı commitine ait başarılı derlemeyi indirir; başarısız build veya değişmiş dalda eski APK kurulumunu açmaz. Kullanıcı Android kurulum ekranından uygulamayı günceller.
